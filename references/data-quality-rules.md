# 数据质量与运行摘要规则

生成器在所有必填指标完成校验、但尚未写入 HTML 前执行数据质量检查。它不会改变指标得分、维度状态、同类参照资格或报告布局。

## 阻断与提示

以下情况属于阻断错误：缺少 41 项营业部指标、负责人数据存在但缺少任一 19 项负责人指标、重复已识别指标、指标 ID 与名称不一致、必填值不可解析为数值、负责人等级不合法。

以下情况属于非阻断的“需复核”提示：

- 推荐基础信息缺失：营业部类别、区域类型、发展阶段、经营标准、负责人或负责人任职时间。
- 本期或上期的线上、线下值缺失；这些字段不影响总值评分，但无法完整核验渠道结构。
- 当 `channel_value_basis` 未声明为 `independent` 时，总值与线上、线下之和的差异超过容差。比例类指标容差为 0.01 个百分点，其他指标容差为总值的 0.5% 或 0.01（二者较大者）。此提示要求确认口径，不把差异直接视为数据错误。
- 占比、转化率、覆盖率、渗透率、活跃率、留存率、执行率、使用率、添加率等有界比例超出 0% 至 100%。完成率和增幅不使用该范围校验。
- 营业部或负责人指标缺少上期值、缺少历史值，或历史期数不足五期。报告保留现有数据，缺少趋势依据时不生成图表。
- 营业部综合得分不低于 85 分而负责人综合得分低于 60 分，或营业部低于 60 分而负责人不低于 85 分。该提示仅要求复核负责人归属、数据期间与口径。
- 输入中存在不属于内置 41 项目录的指标；它们会被忽略。

## 控制台记录

`INPUT_QUALITY=<JSON>` 在写入 HTML 前输出到 stderr，包含主体和同类参照的校验状态、覆盖情况和提示类别。`RUN_SUMMARY=<JSON>` 在成功写入后输出到 stdout，包含：报告主体、输出文件名、数据质量覆盖、五大维度和负责人得分、有效同类样本数，以及每个异常维度选中的关键指标名称。

这两段记录不产生附加文件，也不写入 HTML。调用 Skill 的代理应向用户说明主体数据存在的提示类别；同类参照提示只影响用户对比较结果的复核，不改变同类均值计算。
