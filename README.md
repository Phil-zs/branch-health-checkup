# Branch Health Checkup

为营业部经营数据生成五维经营体检 HTML 报告的 Codex skill。报告包含 41 项营业部指标、19 项负责人指标、同类营业部均值及各维度第一名对比，并可直接在浏览器打开。

## 安装

将本仓库完整下载或克隆后，把 `branch-health-checkup` 文件夹放到 Codex 的个人 skill 目录：

```text
C:\Users\<用户名>\.codex\skills\branch-health-checkup
```

也可以将仓库链接提供给 Codex，并要求安装该 skill。

## 使用

准备一份或多份营业部数据文件（`.xlsx`、`.csv` 或 `.json`），再请求 Codex 分析指定营业部的经营情况。

- 单份数据：生成该营业部的报告，不展示同类比较。
- 多份数据：指定报告主体后，按营业部类别和统计期筛选同类数据，计算同类均值和各维度第一名。
- 如需原因与措施，请同时提供独立的 `原因措施知识库.xlsx`。

输入字段、计算口径和报告版式说明见 `references/` 目录。生成器需要 Node.js 22 或更新版本，且不依赖网络、数据库或本地 Excel 应用。

## 内容说明

本仓库不包含真实营业部数据、负责人信息、知识库或已生成报告。示例模板中的机构名称和数值均为模拟展示内容，实际生成时会由输入数据替换。
